# Documentação CanonWeb
(O projeto é basicamente a tradução de um site feito no framer de um grupo de TCC de design, nada aqui é de autoria minha a não ser o código, todo visual, ideias, branding é de autoria do grupo de tcc canon da etec carlos de campos 2026.)

Projeto de uma página web para visualização de arquivos PDF, desenvolvido a partir de um protótipo criado no Framer e posteriormente adaptado para tecnologias web.

## Tecnologias

- **Python** — responsável pela visualização e gerenciamento dos arquivos PDF.
- **HTML5** — estrutura da página.
- **CSS3** — estilização, layout e responsividade.
- **JavaScript** — utilizado somente quando necessário para animações e interações.

## Objetivo

Desenvolver uma interface simples e intuitiva para visualização de arquivos PDF, mantendo a proposta visual criada inicialmente no Framer.

## Estrutura

```text
projeto/
├── index.html
├── style.css
├── script.js
├── app.py
└── arquivos/
    └── documentos.pdf
```

## Desenvolvimento

A página será construída utilizando HTML e CSS como base. O Python será responsável pela parte relacionada aos arquivos PDF, enquanto o JavaScript será utilizado apenas quando houver necessidade de implementar animações ou interações que não possam ser realizadas com HTML e CSS.


## Hospedagem

O projeto será hospedado gratuitamente utilizando o GitHub Pages, permitindo que a página seja disponibilizada diretamente a partir do repositório do GitHub.

A hospedagem será utilizada para disponibilizar a versão final do projeto na internet, sem a necessidade de contratar um servidor.

## Publicação

O projeto será publicado a partir da branch principal do repositório, utilizando o GitHub Pages.

Após a configuração, o site poderá ser acessado por meio de uma URL no seguinte formato:

https://usuario.github.io/nome-do-projeto/

## Requisitos

Como o projeto utiliza HTML, CSS e JavaScript no lado do cliente, o GitHub Pages é suficiente para hospedar a página estática.

A parte desenvolvida em Python será utilizada localmente ou em um ambiente apropriado caso seja necessário executar código no servidor.
